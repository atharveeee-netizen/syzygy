# GEMINI.md: Autonomous Engineering & Agent Orchestration Directives

## 🏛️ Permanent Global Rule: Dynamic Multi-Agent Project Synthesis

Whenever the user provides any prompt to build, develop, create, or scaffold a project:
1. **Permanent Default Behavior**:
   Automatically invoke the SYZYGY multi-agent synthesis engine:
   ```bash
   python syzygy.py new "<User Prompt>"
   ```
2. **Dynamic Routing As Per Need**:
   Every specialized agent in the SYZYGY suite (`ReconEngineAgent`, `FirecrawlResearchIndex`, `HackathonStrategistAgent`, `AIArchitectAgent`, `ArchitectureDiagramGenerator`, `GitHubActionsAgent`, `ScaffoldAuthAgent`, `ScaffoldTelemetryAgent`, `ScaffoldCryptoAgent`, `AIMLEngineAgent`, `StrixPentestAgent`, `OpenVikingClient`, `STE100Validator`) is evaluated and orchestrated as per the prompt's technical domain and constraints.
3. **Spec-Driven Architecture**:
   Produce and maintain the 8 SDD files (`.spec/PRD.md`, `TechSpec.md`, `Architecture.md`, `AppFlow.md`, `Design.md`, `Rules.md`, `Schema.md`, `Tracker.md`) with zero placeholder mocks and 100% real data.
