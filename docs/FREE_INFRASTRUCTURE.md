# Free Developer Infrastructure & Cloud Registry
## Curated from Free-For-Dev (80k+ Stars)

---

### 1. Compute & Containers
- **Fly.io:** 3 shared-cpu VMs, 3GB storage volume, 160GB egress per month.
- **Koyeb:** Free nano instance (512MB RAM) with global edge network.
- **Render:** Free web services with automated git deployment and free TLS.

### 2. Managed Databases
- **Supabase:** Free PostgreSQL database (500MB), auth, storage, and real-time websockets.
- **Neon:** Serverless Postgres with branching, autoscaling, and 500MB free storage.
- **MongoDB Atlas:** Free 512MB shared cluster.

### 3. Authentication & Security
- **Clerk:** 10,000 monthly active users free, ready-made React components.
- **Firebase Auth:** Free email/password, social, and phone auth (10k/month).

### 4. Hosting & CDN
- **Cloudflare Pages:** Unlimited free requests, unlimited bandwidth.
- **Vercel / Netlify:** Generous free tiers for Next.js, Vite, and frontend frameworks.
