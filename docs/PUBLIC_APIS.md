# Free Public APIs Catalog
## Curated from Public-APIs (300k+ Stars)

---

### 1. Artificial Intelligence & Machine Learning
- **Hugging Face Inference API:** Free tier for running open models.
- **Ollama Local REST API:** Local model execution on `localhost:11434`.

### 2. Science & Academic Data
- **arXiv API:** Free programmatic search and metadata extraction across all arXiv papers.
- **Europe PMC API:** REST API for open access scientific and biomedical publications.
- **PubChem REST API:** Chemical structure, bioactivity, and safety data.

### 3. Open Geocoding & Weather
- **Open-Meteo:** Completely free weather API with zero API key requirement.
- **Nominatim (OpenStreetMap):** Free geocoding and reverse geocoding API.
