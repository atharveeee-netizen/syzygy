## 🏛️ What is SYZYGY?

**SYZYGY** is a curated list of vibecoded tools, agents, and frameworks used by **atharveeee** to build production-grade projects at lightspeed. We are making something that we will use for all future projects to eliminate boilerplate and AI slop.

In celestial mechanics, a **syzygy** (/ˈsɪzədʒi/) is the straight-line configuration of three or more celestial bodies.

In software engineering, **SYZYGY** represents the immutable alignment between:
1. **Natural Language Goals:** Ambiguous human requirements converted into deterministic architectures.
2. **Context Integrity (The 8 SDD Files):** Eliminating AI hallucination via pre-project specifications.
3. **The Single Best Tool for Every Engineering Task:** Zero duplicate bloat — exactly one proven champion tool per domain.
4. **Self-Bootstrapping Agent Protocols:** Any AI agent (Claude Code, Cursor, Codex, Antigravity) immediately knows what to build and how to build it.

## ⚡ The 8-File Spec-Driven Development (SDD) Architecture

Before writing a single line of application code, SYZYGY mandates and generates **8 Foundational Specification Files** in `.spec/`:

```
project-root/
└── .spec/
    ├── PRD.md            # 1. Product Requirements Document (Goals, Personas, Functional Scope)
    ├── TechSpec.md       # 2. Technical Specification (Runtime Stack, Dependencies, APIs)
    ├── Architecture.md   # 3. System Architecture (Mermaid.js Topology, Multi-Agent Mesh)
    ├── AppFlow.md        # 4. Application Flow (User Journeys, State Machine, Handoffs)
    ├── Design.md         # 5. OpenDesign DESIGN.md Contract (Tokens, Typography, Motion)
    ├── Rules.md          # 6. ASD-STE100 Anti-Slop & Agent Directives
    ├── Schema.md         # 7. Protocol, State & OpenViking (viking://) Schemas
    └── Tracker.md        # 8. Implementation Milestones & Verification Checklist
```

## 🚀 Quickstart & Agent Commands

### 1. Scaffold a New Project with the 8 SDD Files
```bash
# Automatically creates <name>/.spec/ with all 8 files
python syzygy.py init "QuantumEngine" --domain web --brand linear
```

### 2. Extract Verbatim Academic Research (43M+ Papers)
```bash
python syzygy.py research "Distributed Byzantine Consensus"
```

### 3. Generate Native Vector PowerPoint Slides (.pptx)
```bash
python syzygy.py deck "Smart India Hackathon Winning Project" --out presentation.pptx
```

### 4. Audit Text Against AI Slop (ASD-STE100 Standard)
```bash
python syzygy.py validate "This cutting-edge framework will revolutionize multi-agent systems."
```

### 5. Run Pre-Flight Security Pentest
```bash
python syzygy.py audit --target http://localhost:3000
```
