# Agent Directives & Engineering Standards (Rules.md)
## Project SYZYGY: ASD-STE100 Compliance & Zero AI Slop Directives

---

### 1. Mandatory Operating Directives for AI Agents
1. **Spec-First Invariant:** Never write application code without first generating and verifying the 8 SDD files in `.spec/`.
2. **Single Tool for Single Task:** Always use the #1 designated champion tool from the SYZYGY matrix. Do not introduce competing redundant frameworks.
3. **Deterministic Output:** Code must have complete type definitions, zero placeholder mock data, and full error boundaries.

---

### 2. ASD-STE100 Technical English Rules
- Ban all marketing buzzwords: `"game changer"`, `"revolutionize"`, `"delve"`, `"testament"`, `"cutting-edge"`, `"seamlessly integrate"`.
- Sentences must remain under 25 words. Procedural instructions must remain under 20 words.
- Use active voice with unambiguous grammatical subjects.
- Use approved verbs with singular, clear meanings.
